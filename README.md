# Segundo Cérebro com NotebookLM - Kimi Antonelli

Projeto do Bootcamp Santander + DIO - Prompt Engineering

## Descrição
Criei um segundo cérebro usando o Google NotebookLM (agora Gemini Notebook) para estudar a trajetória de Kimi Antonelli na F1 sem alucinações, usando apenas fontes confiáveis.

## Fontes que usei
1. Site oficial Formula1.com
2. Wikipedia - Kimi Antonelli  
3. Vídeo YouTube sobre a vitória no GP dos EUA 2026

## O que gerei no Estúdio
- Audio Overview - podcast com 2 IAs conversando
- Mapa Mental da carreira
- Guia de Estudos
- Resumo com citações das fontes

## Evidências
Os prints estão neste repositório na pasta principal.

## O que aprendi
O NotebookLM só responde com base nas fontes que eu enviei e mostra de onde tirou a informação. Isso evita alucinação e é perfeito para estudar.
